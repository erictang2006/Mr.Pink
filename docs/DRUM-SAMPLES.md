# Levels transition drum samples

The local WAV files in `public/drums/` come from the [octalmusic/octal-samples](https://github.com/octalmusic/octal-samples) sample library (CC0). They are bundled with the app and require no network connection during a performance.

| App file | Source file |
| --- | --- |
| `kick.wav` | `samples/kicks/punch-01.wav` |
| `clap.wav` | `samples/claps/classic-02.wav` |
| `hat.wav` | `samples/hats/closed-01.wav` |
| `snare.wav` | `samples/snares/snap-01.wav` |
| `riser.wav` | `samples/fx/riser-01.wav` |

`fill.wav` is a short composite of the local kick, snare, and hat samples, generated by `scripts/build_drum_fill.py`.
