# Roses audience view

Roses Performance Mode opens in the audience view. It shows the Roses record artwork, existing reactive effects and note trails, every mapped computer-key label on the piano, a live display of held physical keys, and all playable instrument pads including kick, clap, chords, intro synth and vocal accent. Each instrument pad shows its keyboard key. It hides arming and setup pads, automatic backing pads, queued arming details, backing-source names, tempo/bar/pedal diagnostics and the live/auto legend.

Before playback, **Space** or **Start Performance** shows a silent four-beat visual countdown at the transport's current tempo, then runs the existing `startArmedPerformance` path on the next downbeat. The same four beat lights stay visible during playback and follow the existing Tone transport with the saved metronome visual offset. Space resumes its pedal role once playback begins. Stop, F9, blur, tab hiding and leaving Performance cancel a pending count-in. The transport hides while playing or paused. Press **F10** to reveal or hide operator controls, automatic backing pads and status information. Opening this setup view does not start, stop, reset or reschedule any audio. Each new entry into Performance Mode returns to the audience view. Escape still exits and F9 still performs panic release.

When the armed Roses intro synth loop plays in bars 5–20, an **Intro Loop** display appears below the record. Its four-bar dial and L / ; / ' indicators follow the existing source MIDI and transport. The full-size piano continues to show physical input. Pressing L / ; / ' during this active loop lights the piano and draws a note trail without triggering a second live synth voice. Those keys keep their normal sound before the loop, after it ends, and whenever the loop is off. The display says AUTO because this is the existing preset phrase, not a recording of the first four live bars.

Practice and Sandbox retain their controls and key labels. Interstellar and Levels retain their existing performance designs and labels. Input mappings, audio engines, assets, MIDI, mixing, timing and automatic versus manual playback are unchanged. Silent bass and buildup gestures continue to illuminate the piano through existing input ownership.

The existing output observer remains mounted for the record orb in either view; the display switch does not allocate an audio instrument or change the speaker path. Pad animation observes only the visible pads. The piano retains the original key geometry, pitch guide, key labels and physical highlights in audience view.

Validation: full automated tests and build/type checks. Focused tests verify rendered audience content, visible playable key labels, hidden running transport, preserved operator controls, unchanged start behavior when revealing controls, and pressed-piano highlight geometry.
