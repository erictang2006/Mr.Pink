# Roses audience view

Roses Performance Mode opens in the audience view. It shows the Roses record artwork, existing reactive effects and note trails, a curated piano-label set, a live display of held physical keys, and the retained live instrument pads including kick, clap, intro synth, bass, drop gestures and vocal accent. Each instrument pad shows its keyboard key. It hides arming and setup pads, automatic backing pads, queued arming details, backing-source names, tempo/bar/pedal diagnostics and the live/auto legend.

**October 28 final stage polish:** chord pads **1/2/3/4/5 and I/O/P** are hidden in the audience panel. They remain in F10 operator setup, and their physical input routes are unchanged. The retained pads use four columns on laptop/projector widths, larger type/keycaps, clearer borders and a stronger localized press glow/pop. Rapid live retriggers are detected from actual note attack IDs as well as physical snapshot/pulse state, so a release/repress between display frames can still flash. This reuses the existing 30 Hz pad loop and adds no audio events/listeners or React frame updates; reduced motion skips the pop.

The audience piano labels are limited to **L / ; / '**, **J/H/F/D/S/A**, **Q/W/E/R/T/Y/U/I/O/P**, **=/−/0/9**, and **, / . / /**. A is retained for the existing JHHFFDSAW phrase ending. Shift-label duplicates and other labels (including 2) are hidden. Current section-dependent MIDI positions and actual multi-note chord labels are retained from the full source guide. The complete continuous piano, all physical note support, key illumination and note trails remain; F10 restores the full labels. Practice, Sandbox and other songs are unaffected.

Before playback, **Space** or **Start Performance** shows a silent four-beat visual countdown at the transport's current tempo, then runs the existing `startArmedPerformance` path on the next downbeat. The same four beat lights stay visible during playback and follow the existing Tone transport with the saved metronome visual offset. Space resumes its pedal role once playback begins. Stop, F9, blur, tab hiding and leaving Performance cancel a pending count-in. The transport hides while playing or paused. Press **F10** to reveal or hide operator controls, automatic backing pads and status information. Opening this setup view does not start, stop, reset or reschedule any audio. Each new entry into Performance Mode returns to the audience view. Escape still exits and F9 still performs panic release.

When the armed Roses intro synth loop display is active, an **Intro Loop** display appears in the instrument grid, anchored beneath a retained intro-synth pad in audience view. Its four-bar dial and L / ; / ' indicators follow the existing source MIDI and transport. The full-size piano continues to show physical input. Pressing L / ; / ' during the active automatic loop lights the piano and draws a note trail without triggering a second live synth voice. Those keys keep their normal sound before the loop, after it ends, and whenever the loop is off. The display says AUTO because this is the existing preset phrase, not a recording of the first four live bars. The earlier placement beneath the removed 2 chord pad is superseded.

Practice and Sandbox retain their controls and key labels. Interstellar and Levels retain their existing performance designs and labels. Input mappings, audio engines, assets, MIDI, mixing, timing and automatic versus manual playback are unchanged. Silent bass and buildup gestures continue to illuminate the piano through existing input ownership.

The existing output observer remains mounted for the record orb in either view; the display switch does not allocate an audio instrument or change the speaker path. Pad animation observes only the visible pads. The piano retains the original key geometry, current-route MIDI pitches and physical highlights; only the audience-label projection is filtered.
